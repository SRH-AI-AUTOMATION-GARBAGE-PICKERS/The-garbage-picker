
# Definition of Done v1

An increment is Done only when every applicable check below is **true**.

## 1. Behaviour of the increment (also on a laptop)

- [ ] All issue-specific acceptance criteria have been met.
- [ ] The implemented functionality has been tested and works as expected.
- [ ] No known critical errors prevent the intended functionality.
- [ ] Another team member has reviewed or verified the result.

## 2. Evidence we keep

- [ ] Code or documentation changes are committed to the GitHub repository.
- [ ] Evidence of successful testing is available (terminal output, screenshots, logs, or videos).
- [ ] Relevant documentation has been updated.
- [ ] The GitHub issue contains links to the relevant commits and evidence.

## 3. Safe operation (from S4)

The following checks apply when working with physical robots, starting in S4.

- [ ] The team safety protocol is written and checked by the instructor.
- [ ] The robot has been operated according to the approved safety protocol.
- [ ] No unresolved safety-critical issue remains in the delivered functionality.
